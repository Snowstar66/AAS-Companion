# Epic 14 Retrospective: Test Warning Hygiene

Datum: 2026-05-22
Status: Done

## Resultat

Epic 14 tog bort två sorters lättfixat testbrus utan att ändra beteendet: styled-jsx-attributvarningar från sidebar och saknade actionmockar i framing cockpit-testet.

## Vad som fungerade

- Riktad testkörning efter varje patch gjorde det tydligt vilka varningar som faktiskt försvann.
- Sidebar-ändringen var trygg eftersom CSS-regeln fortfarande gäller globalt via vanlig style-tag.
- Framingmocken matchar nu sidans imports bättre och minskar risken att framtida testoutput maskerar verkliga renderfel.

## Kvarvarande Fråga

Async Server Component-varningarna kräver ett mer genomtänkt testmönster. Nästa slice bör välja mellan att:

- mocka server-only undersektioner på page-testnivå,
- skapa en server-component render-helper,
- eller flytta datahämtning uppåt så klientrenderade testytor inte möter async function-komponenter direkt.

## Rekommenderad Nästa Slice

Skapa en strukturell `server page test harness` för Framing/Outcome/Review page-tests och flytta de återstående async-varningarna dit.
